# Mind-Echo minimal additive revision experiments

This directory is additive and reproducible. It does not overwrite legacy runners, legacy experiment outputs, source JSON, or figure/chart files.

## Source and grouping

- Source visit data: `D:\vscode-project\git-project\Mind-Echo\analysis\emotion_model\experiments\with_caregiver_label_comparison\data\all_data.json`.
- Validated manifest size for this run: 78 visits and 63 unique patients.
- Grouping field: `patient_id` only.
- Grouping limitation: source rows contain no structured `caregiver_id` or `family_id`; these experiments therefore do not claim caregiver- or family-grouped CV.
- Deterministic seed: 2026.

## Commands

Run from `D:\vscode-project\git-project\Mind-Echo`:

```powershell
python analysis/emotion_model/runners/run_mind_echo_revision_main_v2_oof.py
python analysis/emotion_model/runners/run_mind_echo_revision_window_oof.py
```

## Outputs

- `manifest/`: fixed `visit_manifest.csv`, `patient_fold_map.csv`, `visit_fold_map.csv`, and `manifest_metadata.json`.
- `main_v2_oof/`: patient-grouped main V2 OOF metrics for four feature modes and two targets.
- `window_oof/`: separate anxiety/depression OOF metrics for windows 4, 6, 8, 10, 12, 15, and `full_text` using the same manifest and patient folds.
- No figures or charts are generated by these runners.

## Baselines and uncertainty

For every held-out fold, the majority baseline predicts the training-fold majority label only; ties choose class 0. The seeded random baseline draws Bernoulli labels using the training-fold positive prevalence and deterministic seed/fold/target offsets. Metrics are pooled over OOF rows and include patient-level bootstrap percentile 95% CIs with 2000 draws by default.
