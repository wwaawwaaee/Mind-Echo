In addition to the proxy zero-shot experiment, we further evaluated the current large model directly on the held-out with_caregiver test set using a true zero-shot setting, without any additional task-specific training. On the anxiety task, the direct LLM judgment achieved balanced performance across positive and negative classes (ACC = 0.833, F1 = 0.833, Balanced ACC = 0.833; confusion matrix = [[5, 1], [1, 5]]). On the depression task, the model showed a more conservative prediction pattern, reaching ACC = 0.667 and F1 = 0.750, with perfect precision and specificity (both 1.000) but lower recall (0.600), indicating that several positive cases were missed. Compared with the best traditional baseline, the direct LLM zero-shot result was clearly stronger on anxiety, while on depression it was comparable in F1 but more conservative in positive-case detection. These findings suggest that direct large-model zero-shot inference may provide competitive screening performance in small-sample outpatient settings, although evaluation-protocol differences should be explicitly acknowledged.
